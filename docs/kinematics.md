列车几何约束的拆解：
对于一节车厢，我们可以从几何约束的层面将其分为三层：
- Axle（车轴或轮对）
- Bogie（转向架或车轴组合）
- Wagon（车厢）
它们之间通过转轴相连。因为两点确定一条直线的基本原则，车厢必须呈现如下构造：
Wagon:{
    Bogie:{Axle, Axle},
    Bogie:{Axle, Axle}
    }
这个结构与绝大多数常见车厢一致。对于一些常见例外，在下面进行罗列：
1. 没有转向架，车轴直接连接到车厢。常见于老旧车厢，此时取消Axle层级，用轮对直接充当Bogie。
2. 转向架的数量大于2，或转向架上的车轴数量大于2。常见于重型车辆，此时忽略中间的额外转向架或车轴。
3. 蒸汽机车，同时具有固定轮对和转向架，且数目与排列各异，此时需要具体问题具体分析。
4. 铰接式转向架，将铰接处的转向架复制一份，分别绑定到前后两节车厢，从而退化回一般情况进行计算。

几何计算从Bogie一层起算，绕过Axle来节省计算量。
0. Bogie的位置用所在轨道+路程描述，经过简单计算后可得到世界坐标
1. Bogie的朝向与所在点点轨道切向一致
2. 两个Bogie之间距离永远不变，这取决于车厢的结构，但路程之差可能随轨道弯曲而变化
3. 两个Bogie的坐标经过综合，可求得车厢的朝向与位置，进行显示

在数据结构上必须说明一点：Train configurations determine which axles actually receive power.
当实现列车物理相关逻辑时，物理属性精确到每根车轴，因此对于“三层”结构的定义必须准确，方便后续向其中追加内容。

在几何计算上必须说明一点：弧长与割线长有时差别较大
两个Bogie之间距离永远不变，这取决于车厢的结构，但路程之差可能随轨道弯曲而变化。如果混用路程与距离，就会导致车厢被“挤扁”
因此当计算转向架间距时，尝试使用泰勒展开等方式，低成本解三角学问题。以此保证车厢在过弯时，不会因为割线误差而被“挤扁”

关于车厢间的连接
我们粗糙地认为，两个通过车钩连接的车厢，其转向架的间距是定值。这就提供了一个思路：
从第一节车厢的第一个转向架开始，按定义好的间距依次后推，直到最后一节车厢的最后一个转向架。
不过这里存在一个问题，该计算必须按顺序逐步进行，这使得车厢位置的计算成为了关于列车编组长度呈O(2n)的方法，需要警惕性能问题。

## D1 数据结构与元数据

```伪代码
length: float # 用于碰撞判定和boundary计算，是车钩中心距
mass: float

bogie:{
id: int # 应有至少2个bogie
geometric_role: enum (front/rear/mid) # 转向架个数溢出时，front和rear参与几何计算，mid不参与
load_share: float (0~1) # 载荷权重，是一个比例值。没有写死，因为如果车厢载货，货物也算重量
axle_dummy: int (0) # 无动力车轴数量。
axle_powered: int (2) # 有动力车轴数量。目前来讲不讨论车轴属性，所以暂时没用
...
bogie_property: enum # 此处填入该转向架的物理性质类型，作为车厢元数据的一部分，传给物理逻辑
pos: float # 此处描述转向架在车厢轴线上的位置，相减得到间距
}

engine_property: enum # 此处填入该机车（如是）的物理性质类型，作为车厢元数据的一部分，传给物理逻辑
coupler_1_pos: float (0) # 以前端车钩为原点，符合业务习惯，同时用于后续图形对齐
coupler_2_pos: float (length) # 用这些pos加减，可以求出两节车厢间的转向架距离
```

我同意你对TrainState的定义，但是`List[TrainState]`并不合适，velocity等属性重复了，因此使用`Consist`类作。
这是处于两层考虑，一方面列车是一个整体，这样挺合理。另一方面，物理等逻辑可能需要全列车统一结算，特别是存在多个机车时。
也有三个顾虑，一是过度抽象不是好事，二是计算量和复杂度上升了，三是不同车厢接受的弧长等传入并不相同，这块不能放到`Consist`类中

每个转向架、车厢的速度应当是一致的
我们就完全没定义车钩连接约束，因此车钩在几何上不产生约束和影响。这不意味后续不添加车钩相关的物理逻辑。至少目前，Coupler毫无意义。

## D2 弧长/割线求解器
一方面，合理的弧形铁轨，曲率很小。另一方面，一阶展开后余项误差已经到厘米级了，可接受。
原本我们要使用反三角函数：
$$\Delta s = 2R \arcsin\left(\frac{l}{2R}\right)$$
我们直接使用粗糙的：
$$\Delta s = l + \frac{l^3}{24R^2}$$
就完全够用了，而且计算开销也能接受。
