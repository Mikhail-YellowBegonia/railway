吸附功能需求

吸附功能可分为5类，其中第1类和第3类我们已经实现，按优先级可以这样排列：
1. 基础吸附
2. 格点吸附
3. Straight模式和LAlt模式
4. 长度与角度吸附
5. 平行吸附

下面是具体到用例的功能拆分

**基础吸附**
- 吸附到路径或端点

**格点吸附**
- 吸附到格点，粒度与视角缩放有关（不涉及解算方法调整）

**特殊模式**（已实现）
- Straight建造切线
- LAlt强制解算单弧线（需要改进）

**长度与角度吸附**
- （仅限直线建造）按下功能键后，吸附到长度增量，如100m（注意：涉及解算方法调整）
- （仅限单弧线建造）按下功能键后，吸附到角度增量，如±30°（注意：涉及解算方法调整）

**平行吸附**
这部分最复杂
分为Simple Case和Complex Case，以及一个被逃避的特例，详见两张参考图片

Simple Case
对于一个节点，取其切线方向的垂线，并在垂线的固定位置上取一点，作为吸附参考点
我们将这样的参考点称为Parallel Reference Point，一个Node应该能衍生出两个参考点
这个点携带与父Node一样的切线方向约束
这样，对于一系列节点，有一系列吸附参考点，与其距离一致。
从实际效果上来说，如果用户沿着这一系列参考点建造，可以得到一条平行轨道

进阶的情况（这是Transport Fever中可以在一次操作内创造多段平行轨道的原理）
特别地：
如果建造的起点和终点都是Parallel Reference Point，且位于同侧，继续。
寻找两个参考点对应的Node，如果这两个Node间有唯一最短路径，说明用户期望建造这一长串轨道（可能是很多个直线和圆弧）的平行轨道。
将路径上所有的Node找出来，计算这一串Node所对应的一串Parallel Reference Point
将一串Parallel Reference Point首尾相接，完成建造。
注：这是一个及其复杂的过程，涉及了轨道拓扑的查找和计算，实现起来非常困难。我们暂时逃避。

Complex Case
对于一个节点，取其切线方向的垂线，并在垂线的(R-∂,R+∂)位置上取一个线段。一个父Node应该能衍生出两个线段。
如果线段与其它Edge存在唯一交点，将交点作为参考点。称为Projection Reference Point，它携带有那个Edge的切线方向约束。
事实上，我们预期另一条Edge是与本Edge基本平行，且间距基本为R的一条轨道。
如果没有找到这样的交点，退化回Simple Case。
