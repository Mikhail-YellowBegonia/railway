# 寻路调试

按 **F3** 开启/关闭寻路调试，BUILD、PLAY、计划编辑和 Schedule 面板中均可使用。
开启后地图显示 `N{id}`、`E{id} +`，蓝色箭头始终指向 edge 默认正方向
（`node_a → node_b`），不是列车当前行进方向。圆弧标记沿真实曲线绘制。
原有 BUILD 下的 V 键仍可单独切换地图 ID/方向显示，不开启日志。

终端打印 `[ROUTE_DEBUG]`，开启时会显示本次日志的完整路径。
日志写入系统临时目录内独立的 `railway-route-debug-*/routes.jsonl`，每条即时落盘；
同一进程中反复开关会追加到同一文件。关闭游戏不会主动删除日志，但系统可能清理临时
目录，长期保留请复制该文件。它不会进入存档或 Git。

复现时先暂停列车，在执行连挂/折返/前往之前开启 F3，再运行到跳变发生并暂停。
保留日志文件、地图存档，以及涉及的列车、计划条目和异常 edge ID。

日志事件：

- `search.begin/result/error`：每次公开寻路入口的输入、成功/失败与完整有向序列，
  包括同 edge 快速返回、Dijkstra 候选和锚点拼接后的最终计划路径。
  `query` 标识调用，`parent` 关联嵌套搜索，避免把候选路径误认为最终执行路径。
- `train.initial`：开启时正在运行的列车快照。
- `train.assign_route`：下发前/后的真实车头 edge、t、朝向，完整 occupied 和待走 route，
  偏移、目标、距离、车厢 UUID、计划指针与命令。
- `train.reverse_in_place/reverse_for_coupling/_do_auto_reversal/couple_with`：折返或连挂
  前后快照；连挂也记录另一列车和合并结果。
- `occupancy.append`：消费待走 edge 时的占用链、追加 edge 及拼接结果。
- `occupancy.trim_future`：折返或下发新路线时，按实际车头弧长移除占用窗口
  中尚未行驶的整边余量，记录保留/移除的有向序列。

序列例如 `E12- -> E56+ -> E57+`；`+/-` 表示相对默认正方向。
`repeated_edges` 列出同 edge 的所有出现序号（从 1 开始）；这本身不判定错误，
合法绕路或折返也可能重复。`reversal_after` 标明相邻反向同边；
`disconnected_after` 标明前一边终点与下一边起点不相接的位置，可定位非法重复拼接。

追查 E56 时，依次比较最终 `search.result`、`train.assign_route` 和
`occupancy.append`。这样可以区分搜索结果重复、接入占用链时重复，或合法折返。
调试功能只观测，不改变寻路/运动学决策；每次搜索都记录，连挂目标持续刷新时日志
可能较大，建议只在复现窗口开启。

## 2026-10-09：E16 重复消费的根因与修复

日志中的 `E18- -> E16- -> E16-` 不是合法绕路：第一条 E16- 到达 N15，
第二条却从 N16 出发，运动学插值因此把转向架瞬移回 edge 起点。
寻路结果本身正确，错误发生在 `occupied` 与待走 `route` 的接入边界。

占用窗口按整条 edge 保留车尾余量。连挂后实际尾转向架已经位于 E18，
窗口仍含车尾后方的 E16；原地折返把该余量翻到了新车头前方。
于是占用链是 `E18- -> E16-`，但真实车头仍在 E18-。
新命令从真实车头寻路，待走路线也正确包含 E16-。
推进器先走完占用链中的 E16-，再消费路线里的 E16-，产生重复与断裂。

修复在状态转换时恢复数据边界：折返后的占用链只保留到实际车头所在的
edge occurrence；接入新路线也做此规范化，以兼容旧窗口；查询车头不能
用 `occupied[-1]` 代替运动学位置。裁剪按累计弧长定位，保持所有车身坐标。
这不是事后按 edge ID 去重，合法环线与反向同边折返仍被保留。

自动死端折返还有对应的另一面：长编组的新车头可能已经跨过数条 edge，
质点路线却仍从折返点开始。必须按折返后车身覆盖的完整有向前缀消费这些
已覆盖的 occurrence，再接入新车头前方的路线，并重算终点距离。
移除了“上一条计划是 reverse 就禁止寻路折返”的旧规避措施，合法必要的
后续死端折返继续由寻路器决定。

回归验证见 `tests/test_route_occupancy_join.py`（使用日志中的 E16/E18 长度，
真实连挂、折返、前往、逐帧检查所有转向架至停车）及
`tests/test_route_join_contract.py`（旧窗口、手动前往、必要二次折返、
长编组跨多边的自动折返、合法环线 occurrence 与节点边界）。
